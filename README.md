# VR Cable — екран ноутбука у VR на телефоні (через кабель)

Windows-програма захоплює весь екран ноутбука (і другий монітор, якщо він є) разом зі звуком і по USB-кабелю
передає на телефон (Android 12+). На телефоні ти опиняєшся в сірій кімнаті, де перед тобою висять екрани.
Потрібен VR-шолом для телефона типу Cardboard (з лінзами).

## Як отримати програми (збирає GitHub, нічого ставити на ПК не треба)

1. Створи порожній репозиторій на github.com і завантаж туди вміст цієї папки (разом із `.github`).
2. Відкрий вкладку **Actions** → дочекайся зеленої галочки (≈5–8 хв).
3. Відкрий завершений запуск → внизу **Artifacts** → скачай **VRCable-Windows** і розпакуй.
   У папці будуть `VRCable.exe`, `VRCable.apk` і папка `tools` (adb та ffmpeg).

## Підготовка телефона (один раз)

1. Налаштування → Про телефон → 7 разів торкнись «Номер збірки».
2. Налаштування → Для розробників → увімкни **Налагодження по USB**.

## Користування

1. Підключи телефон до ноутбука кабелем, запусти `VRCable.exe`.
2. На телефоні підтверди «Дозволити налагодження по USB» (став «Завжди дозволяти»).
3. Перший раз натисни **1. Встановити додаток на телефон**.
4. Натисни **2. Запустити VR на телефоні**, вдягни шолом.
5. Керування в шоломі:
   - **торкнутись екрана** — відцентрувати вигляд (дивись прямо і торкнись);
   - **довге натискання** — змінити силу корекції лінз (3 профілі, підбери, щоб лінії не гнулися);
   - **кнопки гучності телефона** — наблизити / віддалити екрани.

Поки телефон не підключений, ноутбук нічого не захоплює і не навантажується.
Звук іде в телефон; щоб не чути ще й з ноутбука, вимкни його гучність.

## Як це працює (для налаштування)

- Канал: `adb reverse tcp:5599 tcp:5599` — зв'язок йде по USB, мережа та Wi-Fi не потрібні.
- Відео: `ffmpeg` (захоплення `ddagrab`) → апаратне кодування H.264 (NVIDIA NVENC, AMD AMF, Intel QSV;
  якщо їх немає — процесорний x264) без B-кадрів і буфера → декодер телефона у режимі low-latency.
- Екрани ширші за 1920 px зменшуються до 1920 для економії ресурсів.
- Звук: системний звук Windows (WASAPI loopback) → `AudioTrack` у режимі low-latency.
- Якщо кадри відстають, телефон скидає чергу і чекає наступного ключового кадру (до 0,5 с).

## Якщо щось не так

- **Другий монітор показується навпаки / не той** — постав галочку «Поміняти монітори місцями».
- **Кодек обирається неправильно** — видали файл `encoder.cfg` поряд з `VRCable.exe`, кодек переперевірить.
- **Картинка в шоломі «пливе» вбік** — торкнись екрана, щоб відцентрувати.
- **Підключено кілька пристроїв adb** — залиш у USB лише телефон.
- Розмір екранів, відстань між очима та поле зору — константи вгорі файлу
  `android/app/src/main/java/com/vrcable/VRRenderer.java`.
